# Compose the workspace layer you need

Claxedo's framework catalog covers public packages and documented in-repository
composition boundaries. It divides the workspace system into explicit runtime,
relay, capability, orchestration, and control-plane layers. Start with the
boundary closest to the contract you need, then follow its dependency notes.
