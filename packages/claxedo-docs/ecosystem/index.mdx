# Bring the stack you already use

Claxedo Framework sits around existing harnesses and infrastructure. Support depth differs by integration: an ordinary terminal can run any CLI, while a supported Session adapter provides richer lifecycle and event information.

- Coding-agent harnesses and ACP clients
- Skills and scoped instructions
- MCP servers
- Model providers and authenticated CLIs
- Local machines, remote hosts, and supported sandbox drivers

See [Connections and capabilities](/concepts/connections-capabilities) for the authority model.
