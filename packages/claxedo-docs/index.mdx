---

Claxedo is a set of composable TypeScript packages for building coding-agent
products: normalized agent events, a runtime facade over multiple agent
harnesses, a per-workspace host, relay/tunnel plumbing, sandbox management, MCP
tooling, connections, and reusable Agent Extensions.
