One Workspace Host is workspace **infrastructure**, not just chat: six route
families against a sandboxed temp workspace, deterministic, done in seconds —
no agent, no LLM, no keys.

## Run

```bash
bun run recipe:05-workspace-host
```

<Note>
Needs `git` on PATH, nothing else. The host serves a fresh temp directory
seeded with two files and an initial commit — never your checkout.
</Note>

## The core

```ts
import { serve } from "@hono/node-server"
import { createWorkspaceRuntimeApp, loopbackWorkspaceRuntimeExposure } from "@claxedo/workspace-runtime"

const runtime = createWorkspaceRuntimeApp({
  target: { workspaceId: "cookbook-tour", directory: dir }, // pins every route to this dir
  storeRoot: path.join(dir, ".claxedo-runtime-store"),
  exposure: loopbackWorkspaceRuntimeExposure(),
})
const server = serve({ fetch: runtime.app.fetch, hostname: "127.0.0.1", port })
// then: plain fetch against /api/wr/health, /file/all, /find/file,
// /git/commit, /diff/vcs, /process, /events (SSE)
```

Full source: [`src/recipes/05-workspace-host.ts`](https://github.com/kyashrathore/Claxedo/blob/dev/claxedo-cookbook/src/recipes/05-workspace-host.ts)

## Lift this into your app

Two details the recipe encodes that are easy to get wrong: file **writes** go
through `POST /api/wr/git/commit` — a compare-and-swap that takes the
`baseCommit`/`baseBlobSha` from a prior `GET /api/wr/git/snapshot` (the file
routes themselves are read-only); and passing `target` at construction pins
every route to one directory so callers never send directory headers. The
full route reference lives in [API → Workspace Runtime](/api/workspace-runtime).
