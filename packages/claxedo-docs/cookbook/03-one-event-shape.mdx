---
title: "03 — One event shape"
description: "Claude SDK messages and Codex app-server JSON-RPC normalize into byte-identical AgentRuntimeEvent envelopes — and garbage input becomes a diagnostic event, never a throw."
---

A Claude `stream_event` and a Codex `item/agentMessage/delta` come out as
byte-identical envelopes: `type`, `harness`, `threadId`, `raw`, plus the
event's own fields. Even garbage input becomes a canonical diagnostic event —
never an exception.

## Run

```bash
bun run recipe:03-one-event-shape
```

<Note>
Fully deterministic: it replays real-shaped harness payloads (copied from the
adapters' own test fixtures) through the normalizers. No live agents, no
network, no credentials — it prints the same output on every machine.
</Note>

## The core

```ts
const claude = createAgentEventRuntime({
  harness: "claude-sdk",
  threadId: THREAD_ID,
  adapter: claudeSdkAdapter(),
  ...deterministic(),
})

const codex = createAgentEventRuntime({
  harness: "codex-app-server",
  threadId: THREAD_ID,
  adapter: codexAppServerAdapter(),
  ...deterministic(),
})
```

Both runtimes then `ingest()` their own raw dialect and emit the same
canonical stream. Full source:
[`src/recipes/03-one-event-shape.ts`](https://github.com/kyashrathore/Claxedo/blob/dev/claxedo-cookbook/src/recipes/03-one-event-shape.ts)

## Expected output

```text
--- envelope parity: same 'text-delta', two harnesses ---
field        | claude-sdk                       | codex-app-server
type         | text-delta                       | text-delta
delta        | "Hi"                             | "Hi"
harness      | claude-sdk                       | codex-app-server
threadId     | thread-recipe-03                 | thread-recipe-03
raw.source   | claude.sdk.message               | codex.app-server
object keys  | delta,harness,raw,threadId,type  | delta,harness,raw,threadId,type
identical key set: true
all 13 events carry { type, harness, threadId, raw }: true
--- end ---

--- diagnostic contract: bad input is still one event shape ---
unknown claude payload => diagnostic  code=claude_sdk.unmapped_event
codex adapter exception => diagnostic  code=runtime.adapter_error
both are type="diagnostic" with the same envelope: true
--- end ---

one event shape, two harnesses, zero per-harness branching. done.
```

(The full run also prints each raw payload and every canonical event —
`text-delta`, `tool-start`, `tool-input`, `tool-output`, `usage`,
`session-status`, `finish`.)

## Lift this into your app

This is the layer that makes UI and replay code harness-free: consume
`AgentRuntimeEvent` and switch on `type`, never on the vendor. The diagnostic
contract matters in production — adapter bugs and unknown payloads surface as
events in the same stream, so your pipeline degrades visibly instead of
crashing.
