# Session publication

The source reads canonical facts and retained root tombstones from the mounted runtime. Machine publication sends these facts to the hosted authority; local publication persists attention history before sending private control-plane notices.

Initial snapshots seed recovery provenance. The shared publication-origin owner preserves that origin for the same generation and meaningful activity position even when metadata advances the journal through position. New canonical activity observed live remains live through batching and failed publication; stale collected rows cannot replace its origin. No sidebar entrant marker or fanout receipt is produced.

Machine reads and POST acknowledgements belong to the serving authority captured when that flush started. A change to host, enrollment, serving generation or workspace scope resets its attention cursor and fences the prior flush. An old response cannot acknowledge new-authority history, clear its recovery provenance or change retry state. Renewing a token for the same authority preserves publication.

Durable questions, permissions and outcomes retain their exact identities independently of row status and sidebar visibility.
