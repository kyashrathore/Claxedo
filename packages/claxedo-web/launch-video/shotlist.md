# Shot list

## Beat grid

96 BPM, 4/4: beat 0.625 s, bar 2.5 s. Shots change on bar lines; selections and sends land on beats; keystrokes, ticks and clicks are scored from the same timestamps that drive the picture (`cues` in `src/cuts.js`).

## UI state chain

HARNESS (Codex → Claude) → MODELS (each harness on your own account, Ready) → WHERE (studio-mac → checkout, Asleep) → TYPE → SEND → WAKING checkout ("Starting the machine, about a minute") → STREAM → RAN 2 COMMANDS → TERMINAL `dev` → PHONE (the turn finished while away; send from the phone; two-line rows) → MARKETPLACE (add your-org/agent-plugins, turn plugins on) → DEPLOY (Live) → POSTER.

**Carried component:** the composer. It anchors the harness picker (shot 1), wakes the workspace (3), becomes the session's dock (4), the phone's input (5), and the hero loop. Same design throughout; size, content and position change.
