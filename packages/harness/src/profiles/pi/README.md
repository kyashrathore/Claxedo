# Pi profile

Pi 0.85.1 discovers global extensions from `$PI_CODING_AGENT_DIR/extensions` and skills from its agent and project directories. Its `-e` and `--skill` flags add entries to that discovery set. There is no MCP intake. Sources: pinned Pi `docs/extensions.md`, `docs/skills.md`, and `README.md` under `packages/harness/e2e/.artifacts/pi/node_modules/@earendil-works/pi-coding-agent`.

`PI_CODING_AGENT_DIR` also contains `auth.json`, `models.json`, settings, packages and sessions. Replacing it hides the person's login and extensions. Source: pinned Pi `docs/environment-variables.md`. Owner turns use that folder without writing it. Member turns use a Claxedo folder scoped to the workspace and session, so simultaneous members cannot replace each other's credential overlay. Its `models.json` carries broker placeholders for the canonical `PI_LAUNCH_PROVIDERS` from `agent-runtime-contract`, with account selection through `piCredentialProviderIDs`. `providerPlaceholder` owns the projected URL, including its selected API path. The profile owns only Pi's environment variable names and file format. Providers without a binding get no overlay; model discovery lists runnable models only.

Session files are placed under Claxedo state with `--session-dir` for both kinds. This keeps the person's profile files untouched while allowing resume. Pi RPC's `--session-dir`, `--session`, and `get_commands` are documented in pinned Pi `docs/rpc.md`.

Pi has no title generation of its own. The transport installs Claxedo's `claxedo-session-title.ts` extension under the Claxedo state root (`<stateRoot>/extensions`), never in a person's agent folder, and adds it with `-e` to every harness launch; its `/claxedo-title` command completes under the session's model and names the session through `setSessionName`, which Pi announces as `session_info_changed`. The command is Claxedo's own and is not listed to users. Pi clamps `set_thinking_level` to the model's levels and answers success either way, so a turn's effort is read back from `get_state` and a clamped level refuses the turn.
