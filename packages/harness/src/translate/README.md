
Tool images preserve the supplied bytes even when the tool names a file: later reads can return different pixels. Limits measure decoded bytes before constructing a data URL. A plain URL supplies no media type. Host subagent binding requires the self-identifying `claxedo.subagent` result from an observed `create_subagent` call; a tool's text alone is not a binding.

A diagnostic-surface event carries its provider frame once, as a bounded excerpt: the method, the payload's `type`, its byte size and its first 4 KiB. The diagnostic inside carries no second copy, so a journal row never stores a whole frame.
