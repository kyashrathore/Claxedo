# Contributing to Claxedo

Thanks for your interest in contributing to Claxedo, an open-source (MIT) desktop workspace for AI coding agents.

## Ways to contribute

- Report bugs and request features by opening an issue: https://github.com/kyashrathore/Claxedo/issues
- Improve documentation
- Submit pull requests with fixes or improvements

## Pull requests

1. Fork the repository and create a branch from `dev`.
2. Keep changes focused - one fix or feature per pull request.
3. Describe what the change does and why in the pull request description.
4. Make sure existing functionality still works before submitting.

By submitting a pull request, you agree that your contributions are licensed under the project's MIT license.

## Code of Conduct

All contributors are expected to follow our [Code of Conduct](CODE_OF_CONDUCT.md). Instances of unacceptable behavior can be reported to Kanusdlp@gmail.com.
