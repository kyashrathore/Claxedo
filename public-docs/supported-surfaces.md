# Supported Surfaces

This page separates code-supported package/runtime surfaces from product-owned
control-plane concerns.

## Product-Owned Boundaries

| Surface                         | Current status                                                                                                                                   |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Agent Plugins catalog sources | The containing product supplies the Claxedo collection and any already-authorized organization or personal collections. |
| Agent Plugins auth and org UX | The product control plane owns user/org authorization; Connections owns OAuth state and credentials. |
| Agent Plugins projection | The optional module resolves effective activation and contributes immutable artifacts to local or cloud runtimes. |

## Runnable Examples In This Repo

There is no `examples/` or cookbook directory in this repo. For runnable
demonstrations of each package surface, see the per-package READMEs and the
quickstart in [See It All In Action](./see-it-all-in-action.md).
