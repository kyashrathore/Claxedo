help me understand workgraph code

WorkGraph is a work ledger: things that should get done become streams containing goals and tasks; agents execute tasks as numbered runs, and nothing agent-invented starts without your approval.

Core packages: packages/workgraph/src (contracts, domain, application, adapters) with mirrored SQLite + Convex stores. Entry: one command endpoint, 38 typed commands.
