Owner: this chat. Scope: remove stored accounts from Settings → Models while preserving the CLI's machine login and enforcing server ownership. Provider-card changes and unrelated task/transcript edits remain separate working-tree slices.

Implementation:

- The saved row has `owner: null`, so the existing personal-owner deletion rule excluded it. The server now reports `can_remove_team_accounts` only for a verified unsigned-local loopback operator in the single-tenant partition, and enforces that fact on deletion. No creator identity is synthesized and no account record is migrated.
- The account-source wire contract requires an explicit boolean. The UI reads that fact through `useAccess().can("accounts.removeTeam", sources)`, exposes the saved credential ids to the existing removal action, and keeps machine-login ids empty.
- Team Check/Reconnect remain unavailable. Remove and check actions are visible alongside the last-check age; confirmation wraps below the account at phone width.
