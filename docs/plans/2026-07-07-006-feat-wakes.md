## Current Model

A wake is a durable row that resumes an idle session from an out-of-band trigger.
The package supports three trigger types:

- `at`: time or cron schedule.
- `on_event`: external event key delivery.
- `on_approval`: token-based human approval resolution.

The lifecycle is `pending -> firing -> fired`, with `expired` and `cancelled`
terminal states. Firing is at-least-once: a row is claimed as `firing`, the host
`spawnTurn` seam is called, and crash recovery can re-drive abandoned `firing`
rows after the lease expires.

## Host Seams

Hosts provide:

- `WakeStore` persistence.
- `spawnTurn(sessionId, result)` to resume work.
- optional `authorize(actor, workspaceId)` for approvals.
- optional `computeNextRun(cron, after)` for recurring schedules.
- optional budgets and clock/lease overrides.

The package does not inspect transcripts, worktrees, or runtime session state.
