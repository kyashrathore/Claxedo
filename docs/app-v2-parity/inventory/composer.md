# Inventory: composer (COMP)

**Screens covered** (both apps, 1280×800 and 390×844 touch, same daemon, same session "Markdown blocks sample"):
- **Session composer:**
  - idle, focused and hovers;
  - the + menu;
  - the permission menu and the harness/model popover (v1), and the pickers (v2);
  - the slash popover and the @ popover (empty query and "pack");
  - an @ pill, shell mode and 12 lines of text;
  - clearing the draft;
  - an image attached, the mark editor and removal;
  - the drag overlays;
  - the draft after a reload.
- **New-session composer:** the draft pane with its pickers.
- **Phone:** idle, focus, the + menu, the pickers or popover, many lines, and a new session.

Screenshots are in `inventory/composer/shots/<screen>-<v1|v2>-<1280|390>.png`.

**How it was checked:**
- The running apps were driven with Playwright: `e2e/results/comp-inv-1..4.mjs`, deleted afterwards.
- Behavior that changes data (send, stop, queue, the first send of a new session, errors) comes from reading the code. It was not exercised.
- The probes only typed into local drafts (browser localStorage and v2's in-memory store). They never sent, stopped or picked a harness.

**Source prefixes:**
- v1 = `packages/claxedo-app/src/features/session/`. `app-styles/` = `packages/claxedo-app/src/app/styles/`.
- v2 = `packages/claxedo-app-v2/src/composer/`.

**Theme note:** v1 renders with its default theme, which has the Codex surface overrides (`ui-overrides.css`), so the composer card is translucent with 20px corners. v2 renders its own default theme.

## Most visible differences

1. **COMP-105 to COMP-107, COMP-094 (owner-reported):** A new session:
   - **v2:** always starts on Claude Code with no model and effort "low", and sends "low" with every prompt. It opens at the bottom of the pane.
   - **v1:** reuses the harness and model this workspace last used in this browser, then the server's folder harness, then "Select agent". It sends no effort unless the user picks one, and opens centered with the context row.
2. **COMP-025 / COMP-113:** An existing session has no harness, model, effort or permission controls in v2. The toolbar is just "+" and Send.
3. **COMP-006:** The placeholder reads "Ask anything..." instead of "Ask anything, / for commands, @ for context...".
4. **COMP-035:** Send is a 24px dark square with an arrow, not v1's 32px black circle (40px on phone).
5. **COMP-017 / COMP-019:** The "shield Auto" permission chip, its description tooltip and the described mode menu are gone.
6. **COMP-024 / COMP-027:** v1's single harness→model→effort popover is gone. It had Harness and Model sections, model search with descriptions, and the effort slider. v2 shows separate raw "Agent / Model / Effort" menus.
7. **COMP-002:** The card is square-ish (8px corners, opaque) instead of v1's 20px translucent blurred card.
8. **COMP-048:** The slash list lost /docs, the harness's skills and commands (with "custom" badges) and the app commands (/new, /compact, /fork…). It shows one odd "/compact-tabs/open".
9. **COMP-011 / COMP-012:** The + menu is half as wide, has no "Add" heading, shows "MOD U" instead of ⌘U, and has Goal moved or hidden.
10. **COMP-072:** During a running turn, the button is Stop even with text typed, so a click stops the turn instead of sending.
11. **COMP-088 / COMP-110:** Drafts, history and every harness/model choice are lost on reload.
12. **COMP-060 / COMP-059:** In shell mode the toolbar no longer fades away, there's no return-key Send icon, and there's no shell placeholder.
13. **COMP-007:** After select-all + Delete, the placeholder never comes back.
14. **COMP-014:** The + menu "Commands" wipes whatever was typed and replaces it with "/".
15. **COMP-054 / COMP-005:** @file pills are blue instead of v1's brown syntax colour, and the editor text is 13px instead of 14px.
