## Checked and correct
- **Session MCP credential:**
  - Only `/turn-delivery` mints it, behind a live turn lease and the session host's own host id.
  - The audience is checked, the claims are exact, and expiry is at most 10 minutes (really at most 60 s).
  - The URL carries only `?session=`; the token never appears in a URL or a log.
  - Every request re-reads the placement and the creator-is-owner rule, so a deleted or moved session is refused at once.
  - The owner's workspace editor token stays server-side and is recorded with the session id stripped.
  - Putting the runtime verifier first does not let a user bearer pass as a runtime credential.
- **Telemetry:**
  - The track route is signed-caller only and covered by the CSRF origin check.
  - Events and properties are closed sets.
  - Every `*_id`/`*Id` key and every `$groups` value is digested; the ids involved are random, so the digests cannot be reversed.
  - The channel telemetry that carries low-entropy external ids is not composed in production.
- **Image outdated:**
  - The image label is written only when the boot used the driver's image, so a restart cannot leave `imageOutdated` stuck true and loop.
  - The Cloudflare driver never reports it.
- **Idempotent create:** `start_status` requires `creator_actor_id` to match, and the session must still be readable, so another user's operation id gets 403.
- **Devices:** listed per `owner_actor_id`, one enrollment per host (unique key), paused shown as a state.
- **Lifecycle telemetry:** `workspace_stopped` is emitted once per boot (stop and destroy are serialized, and a lease already stopped has no `activeMs`). The first-lease meter fires only on the acquire that wins.
- **S-1:** viewers and session-scoped principals receive no `pty.*` frames, live or replayed.
- **S-2:** `sessionId` is gone from pty Info and the hook binding; `CreateInput` strips it.
- **S-4:** a lease in retry backoff reads as provisioning; boot and provider failures carry their own reason.
- **S-5:** devices are built from every unrevoked enrollment, with online, offline or paused state.

Not checked, because they sit in `claxedo-app` outside the packages I was given: LS-1 stream re-route, principal-scope storage clearing, and the persisted draft Where after its placement is deleted.
