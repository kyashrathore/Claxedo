## Verified non-findings

| Area | Verified defense |
|------|------------------|
| Credential envelope | AES-256-GCM + HKDF-SHA-256 per-org keys + AAD bound to key-id and credential-id; rotation via `KEK_NEXT` drain-on-read; fail-closed on unknown kid/tag |
| Consent gate | `scope:"shared"` fan-out requires the stored `consent` flag (`registry.ts:646`); caller-settable scope is the consent |
| Vercel driver | Brokered secrets splice egress header transforms per allowed host; raw values never enter VM env (`vercel.ts:174`) |
| Config push | `/api/wr/config` requires management JWT (iss `claxedo-control-plane`, aud `supervisor-backplane`, JWKS-verified); unknown-field-rejecting schema |
| Relay JWTs | Alg allowlist (EdDSA/ES256/RS256); per-class iss/aud — no cross-class confusion; workspace_id + host_id bound to request |
| Relay revocation | `isRuntimeAccessTokenActive` wired in Bun + worker entrypoints; open-socket re-checks + exp close timer; `parent_jti` re-checked per lease renewal |
| Relay headers | Inbound strips `x-forwarded-*`/`x-real-ip`/hop-by-hop/`x-claxedo-internal-*`/`x-supervisor-*`; Cookie stripped for user-hosted; CORS re-stamped on responses |
| Relay roles | `viewer` = GET/HEAD/OPTIONS only, denied `/api/wr/pty*`; authorized path is the same decoded path that is forwarded (no `%3F` smuggle) |
| Host tunnel | HTT binds `host_id` + `workspace_ids`; one tunnel per host; WS token via `sec-websocket-protocol` (no URL tokens) |
| MCP runtime credential | HMAC-SHA-256, 32B random secret, fixed header literal (no alg substitution), timing-safe compare, workspace+runtime+session bound, `rotate()` kills all prior |
| MCP sessions | Session store keyed on full credentialKey + bearer digest; `?session=` must match claims; per-session `McpServer`+transport (SDK cross-client advisory N/A); in-flight + session caps |
| MCP tool authz | `assertToolAccess` enforces audience + readOnly + scope + cross-machine per call; destructive tools are human-only + elicitation-confirmed |
| MCP OAuth | RFC 7662 introspection; audience-bound to the MCP resource; `claxedo:admin` restricted to deployment-registered client ids |
| Electron | Navigation can't leave app doc; `window.open` denied; scheme-allowlisted `openExternal`; webview attach pins sandbox/contextIsolation; IPC caller-guarded |
| Local loopback gate | Socket-peer + Host + Origin loopback checks; forwarded-header presence fails closed; remote origins rejected outright |
| Secrets hygiene | No committed secrets; sensitive files `0o600`/`0o700`; git creds via env config never argv; logs reference ids not values |

### Cross-cutting theme: `http:` accepted on trust-sensitive URLs

Seven independent sites accept plaintext HTTP where credentials or trust anchors flow — the single most repeated defect class across the audit:

| Where | What's exposed over http: |
|-------|---------------------------|
| `workerBase()` (H-2) | Cloudflare sandbox API token in verify probe |
| `sandbox-contract` `worker_url` (P-28-adjacent) | Same token, stored credential path |
| `createHttpTokenVerifier` endpoint (P-20) | Bearer tokens + introspection claims (MITM → arbitrary claims) |
| `OidcTokenVerifier` `jwksUrl` (P-38) | Verification keys (MITM → forged tokens verify) |
| `control_plane_url` (P-3, P-43) | Invitation secret + signed-request channel → forged responses |
| Relay `relay.url`/`jwks_url`/`session_authority_url` (P-12) | Tunnel token (ws:) + JWKS anchor |
| opencode-server-adapter `baseUrl` (P-42) | All connection secrets + directory header |
| CLI `CLAXEDO_CONTROL_PLANE_URL` (P-43) | refresh_token + Bearer on the wire |

Recommendation: one shared `requireHttpsUrl(value, {allowLoopback})` helper (helpers already exports `exactHttpsOrigin`-adjacent machinery) applied at every boundary that stores, mints, or transports credentials.
